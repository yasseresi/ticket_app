# Ticket Booking App (Flutter UI)

![Flutter](https://img.shields.io/badge/Flutter-02569B?logo=flutter&logoColor=white)
![GetX](https://img.shields.io/badge/State-GetX-8A2BE2)

A flight-ticket and hotel booking UI in Flutter: home feed of upcoming flights and hotels, search with ticket tabs, a ticket screen with a generated barcode, and a profile page. Built to practise complex custom layouts (ticket cut-outs, dashed separators, `LayoutBuilder`).

> 📚 Built following the dbestech Flutter ticket-app course, then extended with GetX controllers and a hotel-details screen.

## ✨ Features

- Bottom navigation (Home · Search · Tickets · Profile) with a GetX controller
- Custom ticket cards with circular cut-outs and dashed dividers
- "All tickets" and "All hotels" list pages, hotel details page
- Search screen with tabs and promotions
- Ticket screen with a barcode (`barcode_widget`)
